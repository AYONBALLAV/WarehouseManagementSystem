# Warehouse Management System

A scalable Warehouse Management System built with ASP.NET Core Web API and Clean Architecture.

## Features

- Product Management
- Warehouse Management
- Inventory Tracking
- Stock Management
- Stock In / Stock Out Operations
- Stock Movement History
- Role-Based Authorization
- JWT Authentication
- Refresh Token Support
- Repository Pattern
- Entity Framework Core
- MySQL Database

## Architecture

WarehouseManagementSystem
├── WarehouseManagement.API
├── WarehouseManagement.Application
├── WarehouseManagement.Domain
└── WarehouseManagement.Infrastructure

### Layers

- Domain Layer: Entities and business rules
- Application Layer: Interfaces and use cases
- Infrastructure Layer: Database and repository implementations
- API Layer: REST API endpoints

## Technologies

- ASP.NET Core
- C#
- Entity Framework Core
